\section{S'organiser : arborescence et sauvegarde}
% ============================================================

Avant d'installer quoi que ce soit, on met en place une organisation de fichiers claire et une sauvegarde automatique. Tu ne perdras jamais ton travail, et tu retrouveras toujours facilement tes cours et projets.

\subsection{Créer l'arborescence des cours}

\begin{enumerate}
  \item Sur ton disque, ouvrir le répertoire \texttt{Documents}.
  \item Y créer un répertoire \texttt{Passerelle}.
  \item À l'intérieur de \texttt{Passerelle}, créer les sous-répertoires suivants :
\end{enumerate}

\begin{center}

  folder/.style={draw=accentBlue, thin, rounded corners=2pt, fill=accentBlue!8,

\subsection{Synchroniser automatiquement sur Google Drive}

Afin de ne pas perdre ton travail en cas de perte, casse ou écrasement de disque, tu vas synchroniser automatiquement le répertoire \texttt{Passerelle} sur ton espace Google Drive personnel.

\paragraph{Étape 1 --- Mettre en place la synchronisation}

\begin{enumerate}
  \item Télécharger et installer \textbf{Drive pour ordinateur} : \url{https://workspace.google.com/intl/fr/products/drive/#download}
  \item Se connecter avec ton \textbf{compte eduge}.
  \item Appuyer deux fois sur \textit{Suivant}, jusqu'à l'étape de sélection du dossier à synchroniser.
  \item Cliquer sur \textbf{Ajouter un dossier}.
\end{enumerate}

\begin{center}
\includegraphics[width=0.72\linewidth]{images/Drive1.png}\\
\small\textit{Capture d'écran --- ajouter un dossier à synchroniser}
\end{center}

\begin{enumerate}[resume]
  \item Sélectionner le dossier \texttt{Passerelle} créé à l'étape précédente.
  \item Vérifier que \textbf{seul} le dossier \texttt{Passerelle} est coché, puis cliquer sur \textit{Suivant}.
  \item Continuer en appuyant sur \textit{Suivant}.
\end{enumerate}

\begin{center}
\includegraphics[width=0.72\linewidth]{images/Drive2.png}\\
\small\textit{Capture d'écran --- dossier Passerelle sélectionné}
\end{center}

\begin{tcolorbox}[attention, title={Attention}]
Ne synchronise que le dossier \texttt{Passerelle}. Ne coche pas \textit{Desktop}, \textit{Documents} ou \textit{Downloads} : tu risquerais de synchroniser bien plus que nécessaire et de saturer ton espace Drive.
\end{tcolorbox}

\paragraph{Étape 2 --- Vérifier le bon fonctionnement}

\begin{enumerate}
  \item Dans ton navigateur, aller sur ton \textbf{compte eduge} puis ouvrir \textbf{Drive}.
  \item Dans le Drive, cliquer sur \textit{Ordinateurs} $\rightarrow$ \textit{Mon ordinateur} $\rightarrow$ \texttt{Passerelle}.
  \item Tu dois retrouver l'arborescence créée sur ton ordinateur.
\end{enumerate}

\begin{center}
\includegraphics[width=0.72\linewidth]{images/Drive3.png}\\
\small\textit{Capture d'écran --- vérification de l'arborescence côté Drive}
\end{center}

\begin{enumerate}[resume]
  \item Créer un fichier \texttt{test.txt} sur ton ordinateur, dans le dossier \texttt{Web}.
  \item Vérifier qu'il apparaît bien côté Drive (après quelques secondes).
\end{enumerate}

\begin{tcolorbox}[astuce, title={C'est en place}]
Ton travail est désormais sauvegardé automatiquement. Tu es prêt à attaquer l'année de manière organisée.
\end{tcolorbox}

\section{Installation des outils (Windows)}
% ============================================================

\subsection{Node.js}

\begin{enumerate}
  \item Aller sur \url{https://nodejs.org/fr/download} et télécharger la version \textbf{LTS} pour Windows (fichier \texttt{.msi}).
  \item Lancer l'installateur téléchargé, accepter la licence, cliquer sur \textit{Next}.
  \item Dossier de destination : garder celui proposé par défaut.
  \item Écran \textit{Custom Setup} : laisser toutes les cases cochées, en particulier \textbf{npm package manager} et \textbf{Add to PATH}.
\end{enumerate}

\begin{enumerate}[resume]
  \item Écran \textit{Tools for Native Modules} : laisser décoché (non nécessaire pour ce cours), cliquer sur \textit{Next}.
  \item Cliquer sur \textit{Install}, patienter, puis \textit{Finish}.
\end{enumerate}

\begin{tcolorbox}[attention, title={Vérification}]
\begin{enumerate}
  \item Ouvrir une invite de commande (\textit{cmd} ou \textit{PowerShell}).
    \begin{center}
    \includegraphics[width=0.5\linewidth]{images/invit.png}\\
    \small\textit{Capture d'écran --- ouvrir une invite à la commande}
    \end{center}
  \item  exécuter \texttt{node -v} puis \texttt{npm -v} : chaque commande doit afficher un numéro de version.
  \begin{center}
    \includegraphics[width=0.55\linewidth]{images/verif.png}\\
    \small\textit{Capture d'écran --- vérification de l'installation de nodeJS}
    \end{center}
\end{enumerate}
\end{tcolorbox}

\subsection{Git}

\begin{enumerate}
  \item Aller sur \url{https://git-scm.com/install/windows} et télécharger l'installateur 64-bit.
  \item Lancer l'installateur, accepter la licence, garder le dossier de destination par défaut.
  \item Écran de sélection des composants : garder les cases cochées par défaut.
  \item Écran \textit{Choosing the default editor used by Git} : sélectionner \textbf{Visual Studio Code} dans la liste déroulante.
\end{enumerate}

\begin{center}
\includegraphics[width=0.72\linewidth]{Semaine1/images/Git1.png}\\
\small\textit{Capture d'écran --- choix de l'éditeur par défaut}
\end{center}

\begin{enumerate}[resume]
  \item Écran \textit{Adjusting the name of the initial branch} : choisir \textbf{main} comme nom de branche par défaut.
  \item Écran \textit{Adjusting your PATH environment} : garder l'option recommandée du milieu (\textit{Git from the command line and also from 3rd-party software}).
\end{enumerate}

\begin{enumerate}[resume]
  \item Écran \textit{Choosing the SSH executable} : garder par défaut (\textit{Use bundled OpenSSH}).
  \item Écran \textit{Choosing HTTPS transport backend} : garder par défaut (\textit{Use the OpenSSL library}).
  \item Écran \textit{Configuring the line ending conversions} : garder l'option par défaut (\textit{Checkout Windows-style, commit Unix-style line endings}).
\end{enumerate}

\begin{enumerate}[resume]
  \item Écrans suivants (\textit{terminal emulator}, \textit{git pull}, \textit{credential helper}) : garder les options par défaut proposées.
  \item Cliquer sur \textit{Install}, puis \textit{Finish}.
\end{enumerate}

\begin{tcolorbox}[attention, title={Vérification}]
Ouvrir une invite de commande et exécuter \texttt{git -v} : la commande doit afficher un numéro de version.
\end{tcolorbox}

\subsection{Visual Studio Code}

\begin{enumerate}
  \item Aller sur \url{https://code.visualstudio.com} et télécharger la version Windows.
  \item Lancer l'installateur, accepter la licence, garder le dossier de destination par défaut.
  \item Écran \textit{Select Additional Tasks} : cocher \textbf{Add to PATH}, \textbf{Register Code as an editor for supported file types}, et les options \textit{Open with Code} du menu contextuel.
\end{enumerate}

\begin{enumerate}[resume]
  \item Cliquer sur \textit{Install}, puis \textit{Finish} en laissant \textit{Launch Visual Studio Code} coché.
  \item Installer les extensions listées dans le polycopié (Prettier, ESLint, Live Server, REST Client, GitLens).

\section{Git et GitHub}
% ============================================================

\subsection{Configuration de l'identité Git}

À la toute première utilisation de Git sur une machine, il faut indiquer qui tu es : ce nom et cet e-mail seront associés à chacun de tes commits.

\begin{lstlisting}[language=bash]
git config --global user.name "Prenom Nom"
git config --global user.email "ton.email@exemple.com"
\end{lstlisting}

\begin{tcolorbox}[astuce, title={Remarque}]
Cette configuration ne se fait \textbf{qu'une seule fois par machine} : elle vaudra pour tous tes futurs projets Git, pas seulement MiniForum.
\end{tcolorbox}

\subsection{Premier commit local}

\begin{lstlisting}[language=bash]
git init
git add .
git commit -m "Premier commit : structure de base du MiniForum"
\end{lstlisting}

\subsection{Créer un compte GitHub}

Si ce n'est pas déjà fait : aller sur \texttt{github.com}, cliquer sur \textit{Sign up}, et suivre les étapes (e-mail, mot de passe, nom d'utilisateur).

\begin{center}
\includegraphics[width=0.72\linewidth]{images/github-account-01.png}\\
\small\textit{Capture d'écran --- page d'inscription GitHub}
\end{center}

\subsection{Créer le dépôt distant}

\begin{enumerate}
  \item Se connecter sur \texttt{github.com}, cliquer sur le bouton \textbf{+} en haut à droite, puis \textit{New repository}.
  \item \textit{Repository name} : \texttt{miniforum}.
  \item Laisser la visibilité en \textit{Public} (ou \textit{Private}, selon la consigne du cours).
  \item \textbf{Ne cocher aucune case} (\textit{Add a README file}, \textit{.gitignore}, \textit{licence}) : le dépôt doit rester \textbf{vide}, puisque le projet existe déjà sur ta machine.
  \item Cliquer sur \textit{Create repository}.
\end{enumerate}

\begin{center}
\includegraphics[width=0.72\linewidth]{images/github-repo-01.png}\\
\small\textit{Capture d'écran --- écran de création du dépôt GitHub}
\end{center}

\begin{tcolorbox}[attention, title={Piège fréquent}]
Si tu coches \textit{Add a README file}, GitHub crée un premier commit sur le dépôt distant. Ton envoi (\texttt{git push}) sera alors refusé, car le dépôt local et le dépôt distant auront des historiques différents. Le plus simple : recommencer avec un dépôt vraiment vide.
\end{tcolorbox}

\subsection{Envoyer le projet sur GitHub}

Sur la page du dépôt fraîchement créé, cliquer sur le bouton vert \textbf{Code}, onglet \textbf{HTTPS}, et copier l'URL affichée.

\begin{center}
\includegraphics[width=0.72\linewidth]{images/github-repo-02.png}\\
\small\textit{Capture d'écran --- bouton Code, copie de l'URL HTTPS}
\end{center}

Dans le terminal, à la racine de \texttt{miniforum/} :

\begin{lstlisting}[language=bash]
git remote add origin https://github.com/votre-login/miniforum.git
git push -u origin main
\end{lstlisting}

\begin{tcolorbox}[astuce, title={Authentification}]
Lors du tout premier \texttt{git push}, une fenêtre s'ouvre automatiquement dans le navigateur et demande de se connecter à GitHub. C'est normal : GitHub n'accepte plus les mots de passe directement dans le terminal. Il suffit de se connecter une fois --- Git mémorise ensuite la connexion pour les prochaines fois.
\end{tcolorbox}

\begin{center}
\includegraphics[width=0.72\linewidth]{images/github-auth-01.png}\\
\small\textit{Capture d'écran --- fenêtre de connexion GitHub lors du premier push}
\end{center}

\subsection{Vérification}

Rafraîchir la page du dépôt sur \texttt{github.com} : les trois fichiers (\texttt{index.html}, \texttt{style.css}, \texttt{app.js}) doivent y apparaître.

\begin{tcolorbox}[definition, title={Pour la suite du cours}]
Le dépôt \texttt{miniforum} va évoluer chaque semaine. Prends l'habitude, à chaque début de séance, de récupérer les éventuelles mises à jour avec \texttt{git pull}, et de sauvegarder ton travail régulièrement avec \texttt{git add . / git commit / git push}.
\end{tcolorbox}
